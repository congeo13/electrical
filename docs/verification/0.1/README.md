# Slice 0.1 — verification record

**Scope:** Flutter skeleton, navigation shell, drift schema, Greek localisation.
**Done when:** app runs, empty screens navigable, schema migrates.

## How it was run

- Flutter 3.47.6 stable, Dart 3.13.5, Linux x86-64 container.
- `flutter analyze` — no issues.
- `flutter test` — 9 tests passed (5 database, 4 navigation/widget).
- `flutter build linux --debug`, then the built binary was launched under
  Xvfb (virtual X display), driven with xdotool, and captured with
  ImageMagick `import`. Window 390 × 844.
- The SQLite file the app created (`protocol.sqlite`) was opened with
  Python's sqlite3 module to confirm the schema independently of the app.

## Schema as created on disk

`PRAGMA user_version` = 1. Tables (15): corrections, erg_sessions, exercises,
interval_blocks, interval_cycles, log_entries, meal_logs, meals,
measurements, medications, protocols, schedule_items, settings,
spacing_rules, training_plans. Foreign keys are enabled on open and the
test suite confirms an insert with a dangling `protocol_id` is rejected.

## Not checked in this slice

- Not run on an iPhone, an iOS simulator, or an Android device/emulator.
  No iOS or Android build was attempted (no Xcode or Android SDK in the
  container). The `ios/` and `android/` directories are as generated by
  `flutter create` and unmodified.
- No upgrade migration: this is schema version 1 on a fresh database.
  Opening an existing older database is not a case that exists yet.
- Notifications, seed content, and every feature screen: later slices.
- Font rendering of Greek on iOS/Android. On Linux the system font
  rendered all glyphs; the screenshots show that.
